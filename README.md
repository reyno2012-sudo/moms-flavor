# 妈妈的味道 · Mom's Flavor

**把家常菜的做法，和做这道菜的人一起记下来。**

妈妈的味道是一款家庭菜谱与地方美食社区。拍下手写菜谱，记下家人的原话，配上照片，就能把一道菜和背后的故事留在家庭菜谱库。也可以把选好的故事分享到家乡频道，让更多人发现这道菜。

当前版本是可在本地运行的移动端 Web 应用，使用 Node.js 和 SQLite。桌面浏览器采用可交互的 iPhone 预览，随窗口等比例缩放。

## 主要功能

| 入口 | 可以做什么 |
| --- | --- |
| **发现** | 按推荐、关注或最新浏览公开菜谱，搜索菜名、城市和作者。 |
| **地方味道** | 切换本地、家乡或其他城市，浏览当地菜谱和美食专题。 |
| **记录** | 保存手稿、家人的原话和照片，预览故事页面。可选用 AI 整理文本和手稿，再对照原件校对。 |
| **我的家** | 邀请家人加入私有空间，一起校对菜谱、点菜排餐、勾选采购清单和制作家庭菜谱册。 |
| **我的** | 管理自己的菜谱、收藏、关注、复刻记录和推荐偏好。 |

每道菜可以设为仅自己、家庭可见或公开分享。选择公开时，可以逐项选定要公开的故事正文和照片。公开内容审核通过后才会出现在社区，作者也可以撤回。

## 本地运行

需要 Node.js 24 或更高版本，无第三方 npm 依赖。在 Windows PowerShell 中启动应用。

```powershell
npm.cmd run dev
```

打开 [本地应用](http://127.0.0.1:5173/)。在另一个终端运行 `npm.cmd test` 可以执行测试。macOS 和 Linux 使用 `npm run dev` 与 `npm test`。

SQLite 默认保存于 `.data/moms-flavor.sqlite`，可用 `MF_DB_PATH` 指定其他数据库，`PORT` 可改变端口。浏览器中的旧版原型菜谱保留在游客的「我的菜谱」，需要时可重新录入到账号中。

## 体验流程

1. 游客可浏览示例菜谱、全国推荐、地方频道、搜索及单列和双列布局。常住城市、家乡、临时浏览地区和菜谱归属可以分别设置。
2. 在「我的」注册本地账号后，可保存个人记录。在「我的家」创建家庭并生成有效期 7 天的单次邀请码，用第二个账号加入可验证家庭菜谱可见范围。
3. 在「记录」填写菜名、原作者和原话，经人工核对后选择仅自己、家庭可见或公开分享。公开投稿显示独立快照，可单独填写选填的公开说明，审核通过后才能进入发现。作者可在个人原稿详情撤回公开快照。
4. 登录后，点赞、收藏、关注、评论、举报和屏蔽由服务端处理。推荐按地区、关注、新鲜度、真实点赞和收藏排序，并加上作者多样性调整。「我的 → 偏好」可关闭个性化。

在「记录」的「这道菜的故事」填写正文并选择最多三张照片，即可生成预览。第一张照片用作封面，照片说明可以选填。选用公开分享时，可分别勾选故事正文和各张照片，再预览公开页。照片和故事与菜谱一同保存在本地数据库，待审核的公开照片仅在授权审核页可见。

示例菜谱的照片由 ImageGen 生成，作者和初始点赞数用于演示。已登录账号之间的权限、互动和复刻记录使用真实本地数据。

## 家庭菜谱与菜单

- **记录**可以保存原始手稿，也可以粘贴带有「食材」「做法」标题的文字，或导入带结构化菜谱的公开 HTTPS 页面。食材可用 `番茄 | 300 | 克` 格式填写。原话、手稿和来源链接随原稿保存。
- **菜谱详情**显示原作者与记录人，可调整原稿的私有或家庭范围。家庭菜谱的记录人可以为指定家人发出校对邀请。复刻可附成品照和心得，改法可以关联原菜谱另存一版。公开复刻经过审核。
- **我的家**支持点菜、未来七天排餐、周末家宴和同步采购清单。只汇总同名、同单位的确定用量，保留「适量」等原文。家庭菜谱册支持成员共同收录菜谱。
- **地方味道**可以创建由同城已公开菜谱组成的专题，审核后对访客可见。菜谱册可以下载包含照片的 HTML，也可以通过打印预览保存为 PDF。

## 选配文本 AI 和本地审核

将 `.env.example` 复制成 `.env`，填写需要开启的配置，再运行最后一条命令启动。

```powershell
Copy-Item .env.example .env
node --env-file=.env server.mjs
```

- `OPENAI_API_KEY` 和 `MF_AI_MODEL` 都有值时，记录页提供文本整理和手稿识别入口。手稿识别需配置支持图片输入的模型。只有勾选同意后才发送原话或手稿，结果由用户对照原资料校对。没有可靠来源的量或时间显示为未知。
- 设置 `MF_MODERATOR_KEY` 后，本地账号可在「我的 → 内容审核」用口令读取公开投稿及举报。审核队列只展示公开快照字段。通过、退回及作者撤回都更新同一个公开状态。口令和服务密钥由本机运行环境管理。
