# Codex 后续实施路线

本项目是 V0.2 前端原型；所有任务是建议，不代表已完成或确定工期。

| 阶段 | 交付 | 验收 |
|---|---|---|
| S0 | 运行原型、盘点代码、技术栈决策、18页高保真交互 | 核心流程无阻塞，保留五项导航 |
| S1 | 账号、家庭、角色、数据模型、公开快照和媒体上传 | 跨家庭越权拒绝，公开与私有隔离 |
| S2 | AI转写/抽帧、结构化、校对、发布 | 原话可追溯，未知不编造，失败可重试 |
| S3 | 地域/全国发现、搜索、点赞收藏关注评论、审核举报 | 私有/未审核记录不进入公共池，撤回有效 |
| S4 | 陪做计时及版本、复刻反馈、个人数据管理 | 可恢复进度，反馈关联版本，导出删除 |
| S5 | 真实家庭内测、性能与安全测试、成本评估 | 根据留存、复刻成功率、内容质量及成本决定迭代 |

## 起步任务（给 Codex）
读取 AGENTS.md 和 docs；启动项目并验证测试。梳理技术架构与模块依赖，提出可渐进迁移的方案，不直接决定框架或购买云服务。优先提升原型视觉与信息架构，补齐18页中的缺失交互；真实后端开发前提出并评审权限模型、公开快照及审核策略。不得改动原 Space 中的 PRD。

## P0安全验收
- 私有和家庭内容不能从公开接口、缓存、搜索、推荐、媒体链接读取。
- 发布需显式同意，未经审核不得公开；撤回和删除有效。
- 模型失败不丢素材；不确定字段显示未知和原话，用户校对后发布。
- 正式用户之间鉴权与权限测试（当前 localStorage 无此保障）。
- 处理网络中断、重复请求、会话过期、并发编辑；使用真实数据前取得同意。
